# PhotoEditor

Консольный просмотрщик и редактор изображений на C# (.NET). Лабораторная работа №3, вариант 1.

Программа открывает изображения в форматах BMP, PNG и JPEG, позволяет их обрабатывать (поворот, обрезка, замена пикселей, надписи, фильтры, коллажи) и сохраняет своё состояние между запусками.

## Возможности

- открытие и сохранение изображений BMP, PNG и JPEG (формат определяется по расширению файла);
- поворот на 90°, 180°, 270°;
- обрезка по прямоугольной области;
- замена отдельного пикселя;
- наложение надписей (пиксельный шрифт, масштабирование);
- фильтры: негатив, оттенки серого, изменение яркости, изменение цветовых каналов;
- коллажи из нескольких изображений;
- список открытых изображений и переключение между ними;
- сохранение состояния при выходе и восстановление при следующем запуске.

## Структура решения

| Проект | Назначение |
|---|---|
| `PhotoEditor.Core` | Предметная область: модели (`Pixel`, `Picture`, `Collage`), операции над изображениями, кодеки, рабочее пространство и сохранение состояния. Не зависит от пользовательского интерфейса |
| `PhotoEditor.Console` | Консольный интерфейс: разбор команд и цикл ввода |
| `PhotoEditor.Tests` | Модульные тесты (xUnit) |

Вся логика находится в `PhotoEditor.Core`, а интерфейс только вызывает её. Поэтому те же классы будут использоваться в лабораторной работе №4 с графическим интерфейсом.

Основные части `PhotoEditor.Core`:

- **Models**: `Pixel`, `Picture`, `Collage`, `CollageItem`;
- **Operations**: интерфейс `IImageOperation` и операции `RotateOperation`, `CropOperation`, `SetPixelOperation`, `TextOperation`, фильтры `InvertFilter`, `GrayscaleFilter`, `BrightnessFilter`, `ChannelFilter` (общая часть фильтров в `PixelFilter`);
- **Codecs**: интерфейс `IImageCodec`, кодеки `BmpCodec` (собственная реализация BMP) и `ImageSharpCodec` (PNG и JPEG на основе библиотеки SixLabors.ImageSharp), реестр `CodecRegistry`;
- **State**: `Workspace` (открытые изображения и коллажи), `WorkspaceStorage` (запись и чтение состояния в формате JSON).

## Сборка и запуск

Требуется [.NET SDK](https://dotnet.microsoft.com/download) 9.0 или новее. Для PNG и JPEG используется пакет SixLabors.ImageSharp 3.1.12, он подключается автоматически при сборке.

```
dotnet build
dotnet run --project PhotoEditor.Console
```

## Тесты

```
dotnet test
```

## Команды

Номера изображений и коллажей начинаются с единицы. Путь к файлу можно писать в кавычках, если в нём есть пробелы. Регистр команд не важен.

| Команда | Действие |
|---|---|
| `help` | показать список команд |
| `open <путь>` | загрузить файл BMP, PNG или JPEG |
| `save <путь>` | сохранить текущее изображение; формат выбирается по расширению (`.bmp`, `.png`, `.jpg`, `.jpeg`) |
| `list` | список изображений (текущее отмечено `*`) |
| `select <номер>` | выбрать изображение |
| `remove <номер>` | удалить изображение из списка |
| `info` | информация о текущем изображении |
| `rotate <угол>` | поворот (угол кратен 90, можно отрицательный) |
| `crop <x> <y> <ширина> <высота>` | обрезка |
| `setpixel <x> <y> <r> <g> <b> [a]` | заменить пиксель |
| `text <x> <y> <r> <g> <b> <масштаб> <текст>` | наложить надпись |
| `filter invert` | негатив |
| `filter gray` | оттенки серого |
| `filter brightness <N>` | яркость, N от -255 до 255 |
| `filter channels <r> <g> <b>` | множители цветовых каналов (например, `0.5 1 1`) |
| `collage new <имя> <ширина> <высота> <r> <g> <b> [a]` | создать коллаж с цветом фона |
| `collage add <№коллажа> <№картинки> <x> <y>` | добавить изображение в коллаж |
| `collage list` | список коллажей |
| `collage render <№коллажа>` | отрисовать коллаж как новое изображение |
| `exit` | сохранить состояние и выйти |

Пример сессии:

```
> open C:\photos\cat.jpg
> rotate 90
> filter gray
> text 10 10 255 0 0 2 HELLO
> save C:\photos\cat_result.png
> exit
```

## Сохранение состояния

При выходе (`exit`) программа записывает состояние в файл `workspace.json` рядом с исполняемым файлом: открытые изображения, коллажи и номер текущего изображения. При следующем запуске состояние восстанавливается автоматически. Если файл состояния повреждён, он переименовывается в `workspace.json.bad`, а программа начинает работу с пустого пространства.

## Ограничения

- поддерживаются форматы BMP (только 24-битные без сжатия), PNG и JPEG;
- прозрачность сохраняется только в PNG: в BMP она отбрасывается, в JPEG полупрозрачные пиксели накладываются на белый фон; JPEG сжимает изображение с потерями (качество 90);
- для PNG и JPEG используется SixLabors.ImageSharp 3.1.12: для этой версии известны уязвимости при обработке специально подготовленных файлов, а исправленные версии 4.x требуют лицензионного ключа при Release-сборке, поэтому открывайте только доверенные файлы;
- в надписях поддерживаются латиница, цифры и знаки `. , ! ? - :`, остальные символы заменяются знаком `?`;
- файл состояния хранит изображения целиком, поэтому для больших изображений он получается большим.
